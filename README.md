# ARUMONO（テストプレイ版）

ゾンビが迫る閉鎖空間でエリアを開放し、最後に抗ウイルス剤「ARUMONO」を調合して脱出する、2〜6人用の協力ボードゲーム「ARUMONO/アルモノ」のテスト版です。

## ページは3つ

| ページ | ルール | 遊び方 |
| --- | --- | --- |
| `index.html`（オンライン版） | 今までのルール | 全員がそれぞれのスマホやPCで参加して遊ぶ |
| `hotseat.html`（1台回し版） | 今までのルール | 1台の端末を順番に回して遊ぶ |
| `facility.html`（施設ルール） | 新しいルール案 | オンラインでも1台回しでも遊べる |

今までのルールと施設ルールを遊び比べて、最終的にどちらにするか決めるためのテスト版です。

## オンライン版の始め方

1. 1人（ホスト）がページを開き、名前を入れて「部屋を作る」を押します。
2. 表示された4文字の部屋番号を伝えるか、「リンクをコピー」で招待リンクを送ります。
3. ほかの人は名前と部屋番号を入れて「参加する」を押します（招待リンクなら部屋番号は入力済み）。
4. 2〜6人そろったら、ホストが「○人で始める」を押します。

- 自分の手番になると、自分の画面にだけボタンが出ます。
- 1人1手番の制限時間は45秒です（ホストが「なし／30／45／60秒」から変更できます）。時間切れになると、ゾンビはサインなしで伏せられ、何もせずに手番が終わります。
- 引いたゾンビと、自分が伏せたゾンビの中身は、自分の画面にだけ表示されます。仲間にはサインの色でしか伝えられません。
- 手札も自分の画面にだけ表示されます。手札は非公開なので、カード名や効果を伝えてはいけません。「結構いけそう」「何もできなさそう」のような手応えだけ伝えてOKです。
- ゲームの進行はホストの端末で管理しています。ホストは最後まで画面を開いたままにしてください。
- ホストの画面を閉じてしまっても、同じ端末で開き直して「前回の部屋を再開」を押せば続きから遊べます。ほかの人は「再接続する」を押してください。
- 通信はPeerJS（無料の公開サーバーを使ったP2P通信）を使っています。サーバーの準備は不要です。

## テスト用の設定（ホストだけ変更できます）

- 追加ゾンビ：毎ターン、接近の最後に山札から1枚を表向きでゾーン4に置く
- 行動Bで引く枚数：1枚 / 2枚
- 開始エリア：1 / 2 / 3 / 0（途中から始めると、前の研究レポートは表の状態で始まる）
- 1人1手番の制限時間：なし / 30秒 / 45秒 / 60秒
- 研究ファイル：ランダム / A〜F

## 記録とテスト結果の保存

ゲーム中も終了後も、画面上部の「記録」から次のものを確認できます。

- まとめ：エリアごとのターン数、手に入れたレポート、倒したゾンビ、使った／引いたアイテム、調合の回数、最高危険度など
- ターンごとの推移：危険度、撃破数、盤上とエリア内のゾンビ数、手札の合計、アイテム山札の残り
- プレイヤー別：行動A〜E・時間切れの回数、1手番にかけた平均／最長の秒数、撃破数、与えたダメージ
- サインと実際に伏せたゾンビ：どの色のサインのときに、実際はどのゾンビだったか

「ファイルで保存」から、次のファイルをダウンロードできます。CSVはExcelやGoogleスプレッドシートでそのまま開けます。

| ボタン | ファイル | 中身 |
| --- | --- | --- |
| このゲームのまとめ | `arumono_日時_summary.csv` | 1ゲーム1行のまとめ |
| ターン推移 | `arumono_日時_turns.csv` | 1ターン1行の推移 |
| 行動ログ | `arumono_日時_actions.csv` | 誰が・いつ・何をしたかを1行ずつ（伏せたゾンビとサイン、攻撃の対象と結果、調合の結果、手番にかけた秒数など） |
| プレイヤー別 | `arumono_日時_players.csv` | 1人1行の集計 |
| 全データ | `arumono_日時_alldata.json` | 上のすべてと、ゲームの状態をまるごと |
| これまでのまとめ | `arumono_history_日時.csv` | この端末で最後まで遊んだゲームを1ゲーム1行で全部 |

「これまでのまとめ」は端末のブラウザに保存されます。何回かテストしたあとにまとめて保存すると、設定ごとの比較がしやすくなります。

## 施設ルール（facility.html）

アイテムカードを引く代わりに、施設に行ってアイテムを手に入れる新しいルール案です。

### 1ラウンドの流れ

1. **ゾンビを伏せる**：全員が1枚ずつ引いて、サインを付けて伏せる。
2. **行き先を指差す**：全員が伏せたまま、武器庫・弾薬庫・薬品庫・研究所から行き先を選ぶ。相談は禁止。そろったら一斉に公開。
3. **施設の結果**：サイコロを振ってアイテムや弾を手に入れる。手に入れたものは全員の共有。
4. **共有アイテムを使う**：スタートプレイヤーから順に、1人1個まで使う。スタートプレイヤーは毎ラウンド時計回りに交代。

### 施設

| 施設 | 手に入るもの | 上限 |
| --- | --- | --- |
| 武器庫 | サイコロ：1 閃光グレネード／2 釘バット／3 ピストル／4 アサルト／5 ライフル／6 マグナム | 1ラウンド2人まで |
| 弾薬庫 | サイコロ：1〜2→1発／3〜4→2発／5〜6→3発 | 1ラウンド2人まで |
| 薬品庫 | 薬品スプレー小（6が出たら大） | 1ラウンド2人まで |
| 研究所 | 研究レポートの解読が1段階進む | 何人来ても1ラウンド1段階 |

- 上限を超えて集まったときは、スタートプレイヤーに近い順の2人だけがサイコロを振れます。
- 研究所に行った人は、そのラウンドはアイテムを使えません。
- 銃は撃つたびに弾を使います（マグナムは2発、ほかの銃は1発、釘バットは不要）。使ったアイテムは捨て札になります。

### エリアの進め方

- 各エリアのゾンビ山札に「意思のあるゾンビ」が1枚入っていて、いつ出てくるか分かりません。
- 意思のあるゾンビを倒すと研究レポートが手に入ります。そのあと研究所で解読を進め、エリア1は5ラウンド、エリア2は7ラウンド、エリア3は10ラウンドで解読が終わると、次のエリアへ進めます。
- 意思のあるゾンビを倒したあとなら、解読を諦めてすぐ次のエリアへ進むこともできます（そのレポートは読めなくなります）。
- 危険度は100%で止まり、**100%のままラウンドを終えると失敗**です。それまでに薬品スプレーで下げれば続けられます。

### エリア0

- エリア0のゾンビは、それぞれ素材（1〜6番）を持っています。倒すとその素材が共有アイテムに加わります（すでにあれば何も起きません）。伏せた人には、そのゾンビの素材も見えます。
- 研究所は調合室になり、入った1人が共有アイテムの素材で試験調合（2つ）か本調合（4つ）をします。
- 試験調合で爆発したときと本調合に失敗したときは、使った素材を失います。同じ番号のゾンビを倒せばまた手に入ります。

### テスト用の設定

| 設定 | 選べるもの |
| --- | --- |
| 1人が1ラウンドに使えるアイテム | 1個 / 2個 |
| 銃を使ったら | 捨て札（使い捨て） / 残る（弾だけ減る） |
| 研究に必要なラウンド | 5/7/10 / 3/5/7 |
| 開始エリア | 1 / 2 / 3 / 0 |
| 1人の制限時間 | なし / 30秒 / 45秒 / 60秒 |
| 研究ファイル | ランダム / A〜F |

### 記録

「記録」から、今までのルールと同じようにCSV・JSONで保存できます（ファイル名は `arumono-facility_` で始まります）。行動ログには、誰がどの施設に行ってサイコロで何が出たかも入ります。「これまでのまとめ」は今までのルールとは別に保存されます。

## 注意

- テスト版なので、ページのソースを見ると研究ファイルの答えが分かってしまいます。遊ぶときはソースを見ないでください。
- 通信が不安定な場合は、同じWi-Fiにつなぐか、ページを開き直して再接続してください。
